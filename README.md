# Personal Green Portfolio

白を基調にグリーンをアクセントにした、個人Web制作向けの1ページポートフォリオです。

## Concept
- A案「GREEN EDITORIAL」のシンプルで落ち着いたVisual
- B案「GREEN GALLERY」の横スクロール風Works演出
- 「すごい制作会社」ではなく、個人で気軽に頼める雰囲気へ調整
- 本業の合間・隙間時間で制作する個人制作者という立ち位置をAboutで明示
- スクロールReveal、横スクロール、ホバーなどの軽いモーション
- スマホ対応 / prefers-reduced-motion対応
- HTML / CSS / Vanilla JavaScript / PHP

## Customize first
1. `index.html` のプロフィール文・制作実績を自分の内容へ変更
2. `mailto:hello@example.com` を自分のメールアドレスへ変更
3. `php/contact.php` の `$to` を実際の受信先へ変更
4. Worksの仮ビジュアルを実際の制作物の画像・スクリーンショットへ差し替え
5. OGP画像、favicon、canonical、SNSリンクを本番ドメインに合わせて追加

## Local preview
PHPを使わない場合は `index.html` をブラウザで開いて確認できます。
フォームを実際に送信する場合はPHPが動作するサーバーへアップロードしてください。
